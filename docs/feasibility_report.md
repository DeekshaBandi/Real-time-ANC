# Feasibility analysis: FxLMS active noise cancellation of periodic noise

**Author:** Deeksha Bandi
**Scope:** Single-channel and 2×2 MIMO FxLMS, simulation study (MATLAB/Octave)

---

## 1. Objective

Assess whether Filtered-x LMS (FxLMS) adaptive control can cancel periodic
(tonal) noise — e.g. engine firing-order or fan blade-pass hum — and quantify
the achievable attenuation, the conditions for stable convergence, and the
sensitivity to secondary-path modeling error. These are the questions that
gate any move from algorithm to a deployable controller.

## 2. System model

| Element | Model |
|---|---|
| Reference noise | 120 Hz fundamental + 2 harmonics (240, 360 Hz) + low broadband noise |
| Primary path P(z) | FIR, ~40 ms, delay + decay + reflection |
| Secondary path S(z) | FIR, ~20 ms, shorter delay/decay (speaker closer to mic) |
| Controller | adaptive FIR, L = 256 taps, normalized FxLMS |
| Sample rate | 8 kHz |

Paths are generated by `src/make_paths.m`; signals by `src/gen_reference.m`.
See `phase1_reference.png`, `phase1_paths.png`.

## 3. Method

1. **FIR design** (`fir_lowpass.m`): windowed-sinc lowpass, used to bandlimit
   and to demonstrate the transition-width / stopband trade-off across windows.
2. **Secondary-path measurement** (`secondary_path_id.m`): offline NLMS system
   ID with a white-noise probe. Achieved **0.01 % coefficient error, −59 dB
   MSE** — limited only by the injected measurement-noise floor.
   (`phase3_identification.png`.)
3. **Control** (`fxlms.m`): normalized FxLMS using the *estimated* Ŝ(z).
4. **Validation**: step-size sweep and secondary-path-error robustness.
5. **Comparison**: FxLMS vs standard LMS; before/after spectra.

The full derivation is in [`derivation.md`](derivation.md).

## 4. Results

### 4.1 Cancellation
- Single-channel: **43.5 dB** steady-state reduction on the periodic signal
  (`phase4_fxlms.png`).
- Spectrum: tonal peaks at 120/240/360 Hz reduced by ~40–50 dB each
  (`phase6_spectrum.png`).
- 2×2 MIMO with cross-coupled paths: **~44 dB at both error mics**
  (`phase7_mimo.png`).

### 4.2 Convergence vs step size (`phase5_stepsize.png`)
- Stable, high-performance band: **μ ≈ 0.005–0.07** → ~42 dB.
- μ ≥ 0.1 → divergence. μ ≤ 0.002 → too slow to converge in the window.
- The stable band sits below the nominal NLMS limit of 2 because the
  secondary-path delay inside the loop reduces the usable step.

### 4.3 Robustness to secondary-path error (`phase5_robustness.png`)
- Tolerant to **random** coefficient error: ~42 dB held up to 80 % error,
  because broadband error barely perturbs the phase at the low tonal lines.
- Sensitive to **delay** error: cancellation collapses once the delay
  mismatch drives the phase error past ±90° at the highest tone — the
  textbook FxLMS phase condition, reproduced empirically.

### 4.4 Why FxLMS, not LMS (`phase6_lms_vs_fxlms.png`)
At identical μ, FxLMS converges to +42.7 dB while standard LMS **diverges** —
direct evidence that compensating the secondary path in the gradient is
essential, not optional.

## 5. Limitations & assumptions

- **Simulation only.** Paths are synthetic FIR models, not measured responses;
  no real transducer nonlinearity, quantization, or sensor noise beyond the
  injected term.
- **Time-invariant paths.** Real cabins/ducts vary with temperature, load, and
  speed; on-line secondary-path tracking would be needed in production.
- **Stationary tones.** Frequency is fixed; a real engine sweeps RPM, which
  stresses convergence speed and may favor a frequency-domain or RLS variant.
- **No actuator/saturation limits** modeled.

## 6. Path to deployment

1. Replace synthetic paths with **measured** transfer functions (swept-sine /
   MLS) on the target geometry.
2. Add **on-line secondary-path modeling** and **leakage** for time-varying,
   bounded-effort operation.
3. Track RPM with an **order-tracking** reference (tach) so the controller
   follows the sweep.
4. Port the steady-state inner loop to **C** for real-time execution on the
   target DSP/MCU (Phase 9) and profile latency/MIPS.
5. Validate on a **MIMO** rig with the true number of actuators/mics.

## 7. Conclusion

FxLMS is **feasible** for periodic-noise cancellation: ~43 dB single-channel and
~44 dB on a 2×2 MIMO configuration in simulation, with well-understood and
quantified stability and robustness behavior. The remaining risk for production
is concentrated in **secondary-path accuracy and time-variation** — addressable
with measured paths and on-line modeling — and in **real-time implementation**,
addressed by the C port.
